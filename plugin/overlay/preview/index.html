访问控制

列出的设备保留原有 TCP 与 DNS 路径，交给设备自身 VPN 处理。每行一个 MAC 地址，也可用逗号分隔，最多 32 个；留空则不旁路设备。保存并应用后生效。

关闭设备自身的 TUN / VPN 后，需要移除此旁路，才能使用路由器代理。此设置不会关闭设备自身的 VPN。

游戏加速规则优先；其余境外 IPv4 TCP（如 YouTube）走路由器代理。UDP 由 UU 或原网络处理，DNS 沿用 UU 与路由器的现有规则。

每行一个 MAC 地址，也可用逗号分隔，最多 32 个。每台设备只选择一种策略，请勿与上方旁路列表重复。保存并应用后生效。

支持 h2、http/1.1，可用逗号分隔；留空使用自动协商。

每行 原域名=目标域名或IPv4，也可用逗号分隔，最多 32 条。使用 ASCII 域名；来源也支持 IPv4。重复来源须指向同一目标，映射链最多 4 跳。

仅替换 AnyTLS 节点的连接目标，保留节点 SNI。留空使用节点原地址；此设置不修改设备自身 VPN / TUN 或全局 DNS。

附加功能

调整路由器的 HTTPS 检测频率与失败判定。更短的间隔会增加检测流量；此处不控制 UU 或设备自身 VPN。保存并应用后生效。

轮 · 1–5

所有目标连续未通过达到此次数时，显示连接检测失败；部分目标未通过时显示连接波动。
